# Publication source snapshots
Each dated collection retains a public browse metadata response, the homepage count/version observation, a bounded publication-header excerpt for each ORCS /Dataset/ page, and per-page retrieval receipts.

The current collection is 20261004-v01. Receipts retain each reserved attempt, source URL, status, UTC retrieval time and SHA-256 for the saved header. No linked supplementary file contents, publication-screen downloads, screen-score endpoints or external bibliographic pages are fetched.

The browser's listing response supplies explicit screen-to-publication-page associations. Publication headers are preserved independently of any filtered search. To refresh the resource, use a new dated source collection and retain the old evidence.
