# Third-party metadata

The MIT license applies to DeathMap-AI project code and original documentation. It does not relicense third-party metadata, ontology content, publication text or owner-supplied validation materials.

Included resource-derived files under `data/orcs/`, `data/cellosaurus/`, and related vocabulary/reference documents retain source identifiers and provenance. Consult their manifests and receipts for source URLs, retrieval dates and transformations. Use of these materials remains subject to the applicable upstream terms. No blanket claim that all included resource metadata is MIT-licensed is made.

The production pilot uses saved BioGRID ORCS publication/screen metadata and saved Cellosaurus reference annotations. Linked supplementary files and experimental dataset contents were not retrieved. Local validation materials and superseded development outputs are excluded from the Git source release; curated ORCS and PubMed review outputs are included with provenance. PubMed publication metadata and NCBI GEO, BioProject and SRA summaries are third-party resource content under their upstream terms, not relicensed by the project. Publication text inside native metadata responses is retained for traceability; the earlier repository stages did not retrieve full-text articles or experimental files.

The curated GEO collection also includes native NCBI GEO Series/sample metadata,
Europe PMC accession annotations and literature-data links, and request receipts.
These retain upstream terms and original identifiers; the project MIT license
does not relicense them. Annotation text supplied by metadata services is retained
as returned, without retrieving the underlying publication bodies or supplements.

The BioStudies–ArrayExpress collection includes native PageTab study metadata,
IDF/SDRF descriptive metadata, Europe PMC accession annotations and request
receipts. These remain source-derived metadata under their upstream terms, with
original identifiers and provenance. Experimental data files were not retrieved.

The PMC supplemental collection preserves native article XML, supplementary-file
labels and descriptions, cloud object metadata, and retrieval receipts. Article XML
may contain the full article even though the collector interprets only identity and
supplementary elements. These source materials retain their upstream terms and
article-specific licenses, as recorded in the XML; the project MIT license does not
relicense them. Supplemental and media file contents were not downloaded.
