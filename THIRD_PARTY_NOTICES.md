# Third-party metadata

The MIT license applies to DeathMap-AI project code and original documentation. It does not relicense third-party metadata, ontology content, publication text or owner-supplied validation materials.

Included resource-derived files under `data/orcs/`, `data/cellosaurus/`, and related vocabulary/reference documents retain source identifiers and provenance. Consult their manifests and receipts for source URLs, retrieval dates and transformations. Use of these materials remains subject to the applicable upstream terms. No blanket claim that all included resource metadata is MIT-licensed is made.

The production pilot uses saved BioGRID ORCS publication/screen metadata and saved Cellosaurus reference annotations. Linked supplementary files and experimental dataset contents were not retrieved. Local validation materials and superseded development outputs are excluded from the Git source release; curated ORCS and PubMed review outputs are included with provenance. PubMed publication metadata and NCBI GEO, BioProject and SRA summaries are third-party resource content under their upstream terms, not relicensed by the project. Publication text inside native metadata responses is retained for traceability; no full-text articles or experimental files were downloaded.
