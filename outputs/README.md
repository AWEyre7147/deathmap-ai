# Generated review outputs

Use this directory for temporary review workbooks and new run directories.
Completed ORCS deliverables are in `data/orcs`, including the final
`Enrichment-Synthesis.xlsx`, canonical JSON and export manifest.
Superseded synthesis previews and intermediate run copies have been removed.

Generated contents are ignored by Git. New runs must use new directories;
disposable tests clean up their fixtures. Authoritative source metadata and
identifier registries remain outside this temporary output workspace.
