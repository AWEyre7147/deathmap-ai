external DeathMap-AI v0.1 specifications. It became the repository source of truth
on 2026-09-27.

## [SP-2] Authority

`AGENTS.md`, the repository `README.md`, and the documentation index name this
directory as the authoritative v0.1 specification location. Historical references
to the deleted OneDrive directory are no longer operative.

## [SP-3] Conflict rule

If an implementation-facing note conflicts with an accepted specification, stop
and present the conflict to the project owner. Do not silently choose one source.

Later specifications may supersede earlier ones only when they identify the
superseded decision explicitly. Preserve historical runs and their documentation.
