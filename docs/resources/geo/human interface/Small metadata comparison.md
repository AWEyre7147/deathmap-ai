## [HM-1] How to use this instead of an entire database
For each row, ask: which intended property is directly reported, which needs interpretation, and which is missing? A useful small review table for future samples would put record identity, organism, reported model, screening/library text, assay, publication association and unresolved issues side by side.

Do not mark a model negative simply because a summary omits it. A detail lookup may answer the question; if not, preserve unresolved status. Review burden should be measured in a small authorized sample before scaling.
