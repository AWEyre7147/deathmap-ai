# Native GEO: filter and searchable-field menu

## [GF-1] Scope
All 31 fields exposed by the supplied GEO DataSets (Entrez gds) EInfo snapshot are listed below, including its hidden UID field. This is complete for that snapshot, not every present/future GEO website feature or GEO Profiles field. It is **not the OmicsDI filter menu**.

A fixed-choice or controlled-vocabulary field links to its own note. Complete current enumerations were not retrieved; notes show evidence-backed choices and explicitly mark gaps. The saved XML's TermCount is a count, not an allowed-value list. Three external documentation operations (one blocked open, two search queries) were used; no discovery queries, live enumerations, downloads or code changes.

## [GF-3] How to read this menu
Filters appear inside the native term expression: a field-qualified organism condition is still a structured organism restriction. Free-text fields restrict where text is matched; they are not curated biological categories. Quoting/grouping syntax is interface-specific. Treat examples as documentation or saved observations, not new validation of every field.

Useful starting controls: Entry Type and Organism. DataSet Type, publication links, dates and sample/probe thresholds are available controls but not mandatory pilot gates. Cancer-cell category, immune lineage, organoid identity and CRISPR screening/library modality have no demonstrated curated equivalents in this snapshot. Attribute fields do not solve that gap merely by existing.

Record release dates differ from associated article dates. UID is an Entrez lookup identity, not a PMID: the schema's generic description mentions publication but does not make GEO UIDs publication identifiers. Samples/probes do not measure CRISPR library breadth.

Sources: [saved EInfo XML](../progress/perplexity-01/evidence/native-geo-einfo.body) and [request metadata](../progress/perplexity-01/evidence/native-geo-einfo.meta.json); [supplied query-documentation extraction](../progress/perplexity-01/evidence/official-geo-query-documentation.json); [official guide](https://www.ncbi.nlm.nih.gov/geo/info/qqtutorial.html). Direct guide access returned CAPTCHA; search excerpts corroborated field examples. No CAPTCHA bypass.

## [GF-4] What remains incomplete
The full indexed menus for categorical fields need one bounded Advanced Search index inspection in an accessible environment. Large Organism/MeSH vocabularies should remain lookup-based rather than reproduced as enormous files. No resource-intensive database compilation is required. Do not claim an exact complete enum until its terms have been inspected.

Learning checkpoint: the schema tells us which fields exist; the term index tells us which values are indexed; successful probes establish how specific restrictions behave. These are separate evidence layers.
