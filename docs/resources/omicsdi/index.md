# OmicsDI — retired discovery route

OmicsDI no longer drives discovery or current enrichment. Historical query implementations and limits are retired. A possible future accession-led relationship lookup is an unapproved backlog idea, not a required dependency.

Current work uses repository-specific interfaces to enrich the retained ORCS publications and screens. Consult the [current iteration](../../development/v02%20-%20ORCS%20Pilot%20Enrichment/README.md) and [module specification](../../specifications/module-01-evidence-discovery.md).
