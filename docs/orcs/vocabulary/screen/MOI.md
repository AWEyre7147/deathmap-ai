# MOI

## Technical definition

Multiplicity of infection of the lentiviral library: an operator ('=', '<', '~', '>') and a value. Low MOI (about 0.3) ensures most cells receive one guide.

## Plain-language description

How many guide-carrying viruses were used per cell. A low number means most cells got only one gene change, which keeps results clean.
