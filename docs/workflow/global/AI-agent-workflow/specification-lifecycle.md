# Specification lifecycle — pending rules

Status: not yet defined or adopted. This note reserves a place for rules that
will govern specification maintenance once agreed with the owner.

Questions to resolve:

- When does a change require a new project version rather than an update?
- When should an existing vision or module specification be revised?
- When is an additional module or other specification justified?
- How are draft, accepted and superseded states recorded?
- How are prior versions and their decisions preserved?
- What should an agent record when updating specifications or logging a session?

Until these rules are agreed, act within the owner's explicit document-change
request. Do not automatically create versions, additional specifications or
required current-work-session documents. Logs record work; they do not authorize it.
