# Accession Labels

Apply when this note is included in a project conversation. Adapted from the
owner's `Primary Workflow/Accession Labels.md`, with the owner's explicit
per-reply lettering taking precedence over that note's continuous A01 sequence.

## Purpose

Use short labels so the owner can reference findings, questions, decisions and
deliverables. These are conversation labels, not publication or dataset accessions.

## Format and continuity

- Prefix each substantive item with a bold label: **A1 —**, **A2 —**.
- The first assistant reply in a new conversation uses A; the second uses B;
  the third uses C. Reset the point number to 1 for each reply. After Z use AA,
  AB and so on. A reply includes its commentary and final answer, not tool calls.
- Commentary consumes point numbers within the same reply's letter. Do not
  reuse a label for a different new item. A coherent paragraph, table or short
  list can share a label; do not label every sentence or bullet.
- Give distinct decisions or questions separate labels.
- For this existing conversation, transition from the prior A-series to B for
  the adoption reply, then C for the next reply. Preserve all historical labels;
  never retrospectively renumber them.
- Reference earlier items inside a new item using their original labels.
  A user referencing an earlier label is not requesting a numbering restart.
- If continuing history is unavailable, acknowledge that once; do not claim
  globally unique labels or invent continuity.

## Tables, artifacts and saved notes

Use row labels when the owner needs to answer rows individually. Preserve
established document decision labels instead of renumbering those documents.

Keep conversation labels outside reusable emails, dispatch messages and other
copyable artifacts unless they belong in the artifact itself.

Use descriptive saved-note titles. Include conversation/project context when
recording a label for traceability: A1 can recur in another conversation. Labels
do not replace citations, file links or genuine database accession identifiers.

Apply automatically without repeatedly explaining the convention.
