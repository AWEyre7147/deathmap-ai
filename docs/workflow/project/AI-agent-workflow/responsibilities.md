# User and AI-agent responsibilities

## User

- Define scientific goals, inclusion boundaries and acceptable evidence for attribution and grouping.
- Curate repository-interface notes and choose resource priorities using coverage and ORCS overlap.
- Review proposed retrieval contracts, uncertain mappings and generated outputs.
- Authorize material implementation, retrieval, resource expansion and publication steps.

## AI agents

- Read active specifications and applicable workflow instructions before acting.
- Distinguish owner decisions, research observations, assistant proposals and exploratory ideas.
- Compare native interface notes with programmatic behavior within the authorized scope; do not assume equivalence.
- Propose concrete bounded tasks with effort, preserved files, checks, expensive-pass limits and stopping conditions.
- Implement only authorized work, retaining source identifiers, field evidence, uncertainty and recovery paths.
- Record accepted decisions in decision-log and unapproved possibilities in ideas-questions. Log actual work without turning logs into specifications.
- Report changed files, focused checks, limitations and remaining questions. Do not repeat expensive work without a relevant reason and accepted scope.

## Shared boundaries

Current iteration is v02 ORCS repository enrichment. Publication identifier resolution is implemented; native repository enrichment and screen groups still require concrete contracts. The longer-term normalization, analysis and ligand–receptor annotation stages are deferred.

No mandatory multi-AI workflow exists. Optional external findings are evidence to examine, not authority. Accession labels are active; Explore/Remember/Decide/Do terminology and automatic specification lifecycle rules remain proposed. The owner's ordinary-language instructions remain sufficient.
