# Workflow instructions

The repository's `AGENTS.md` links the applicable instructions so future agents
can discover them. Folder names alone do not activate instructions.

- `global/AI-agent-workflow`: reusable conversation rules being developed here.
- `global/standards`: reusable documentation and code standards.
- `global/specifications`: standalone project-vision and module-specification
  templates and the agreed template structure. Lifecycle rules remain pending.
- `project/AI-agent-workflow`: instructions specific to this project, including
  recording decisions and ideas in the current development iteration.

The global folder is not installed in personal ChatGPT or Codex settings.
The proposed user notation remains inactive. New chats follow the accession
scheme in `global/AI-agent-workflow/accession-labels.md`; historical IDs stay unchanged.

Finding-card instructions remain available as a research format. Their presence
does not require a collaborative Perplexity workflow.

[User and AI-agent responsibilities](project/AI-agent-workflow/responsibilities.md)
defines who supplies scientific decisions, investigates interfaces, proposes
retrieval contracts, implements authorized work and reviews uncertain results.

## Handoff scope and resource boundaries

[Codex Handoff Rules](global/AI-agent-workflow/codex-handoff-rules.md)
apply when preparing tasks: estimate effort, define one deliverable, preserve
accepted decisions, bound checks and expensive operations, and state when to stop.
The [repeated rebuild incident](global/AI-agent-workflow/incident-repeated-rebuilds.md)
is retained unchanged as a historical example. It does not authorize inspection
of the incident's other project or regeneration of this project's outputs.

Both notes are adopted locally through `AGENTS.md`; copying them here does not
install instructions in other projects or create an automatic resource cap.
